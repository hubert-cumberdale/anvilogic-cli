# v0.3.5 hardening and adoption milestone

The public GitHub
[`v0.3.5 — Hardening and Adoption` milestone](https://github.com/hubert-cumberdale/avl-cli/milestone/1)
tracks release blockers separately from later product opportunities. The milestone does not approve
new endpoint families, mutation semantics, registry facts, distribution channels, Beta status, or
PyPI publication.

## Release blockers

- [#7: Unify strict structured-document loading](https://github.com/hubert-cumberdale/avl-cli/issues/7)
- [#8: Separate invocation orchestration from CLI parsing](https://github.com/hubert-cumberdale/avl-cli/issues/8)
- [#9: Harden OpenAPI 3.0 contract conformance](https://github.com/hubert-cumberdale/avl-cli/issues/9)
- [#10: Add aggregate-only offline adoption harness](https://github.com/hubert-cumberdale/avl-cli/issues/10)
- [#11: Update hardening and adoption documentation](https://github.com/hubert-cumberdale/avl-cli/issues/11)
- [#12: Complete release verification matrix](https://github.com/hubert-cumberdale/avl-cli/issues/12)

Release blockers remain open until their implementation is reviewed and the required checks pass.
Closing a blocker records completion; it does not expand the scope of the milestone.

These issues intentionally have no v0.3.5 milestone. They cover every limitation recorded in
`STATE.md` and keep automatic pagination, resource mutations, mutation retries, broader stability
claims, Beta status, and PyPI gated on reviewable evidence.
